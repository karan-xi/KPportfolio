The Course Manager App is a multi-tier web application that lets students, instructors and administrative staff manage courses, track enrollment and send automated email notifications. It follows the Model-View-Controller pattern throughout, so data access, business logic and presentation stay in separate, testable layers.

Problem & objectives

Educational institutions often run course catalogs, enrollment tracking and status notifications as separate, disconnected systems. That fragmentation makes it easy for a student's enrollment status to fall out of sync with what staff actually see. The app was built around three objectives:

  • Centralized management: one interface for administrators to create, update and manage both courses and student records.
  • Automated communication: integrated email notifications for enrollment confirmations and status updates, so no one has to track them manually.
  • A responsive, dependable UI: a Bootstrap-based interface backed by Entity Framework Core for reliable data operations.

Architecture & tech stack

The app is structured as an MVC application to keep concerns separated cleanly:

Architecture layers and the technologies behind each
LayerTechnologyResponsibility
BackendASP.NET Core 8 / C#Routing, dependency injection and middleware, configured in Program.cs.
Data & ORMEntity Framework CoreMaps Course, Student, StatusEnrollment and EmailSettings to the database via ApplicationDbContext.
FrontendRazor views (.cshtml)Server-rendered pages styled with Bootstrap, with jQuery for client-side validation.
ServicesEmailService.csWraps SMTP configuration and dispatches confirmation and status-update emails.

Data integrity is enforced at the model level as well as in the UI. For example, a course's room number must match a strict pattern, one digit, one capital letter, two digits, such as 3G15, using a [RegularExpression] data annotation on the Course model, checked both server-side and via jQuery validation in the browser.

Key functional modules

  • Course management (CoursesController.cs): full CRUD on the course catalog, through Create, Edit, Index and Manage views.
  • Enrollment & student tracking (EnrollmentController.cs, student records on Course): tracks each student's status through a StatusEnrollment enum: Confirmation Message Not Sent, Confirmation Message Sent, Enrollment Confirmed, or Enrollment Declined.
  • Automated notifications (EmailService.cs, EmailSettings.cs): configurable SMTP credentials in appsettings.json drive an HTML confirmation email with one-click confirm and decline links, generated per student and per course.

Deployment & version control

Version control ran through Git, pushed to GitHub. Compiled build artifacts (bin/, obj/) and local IDE cache files (.vs/) are excluded via .gitignore, which keeps the repository free of files that cause permission-locking errors and unnecessary bloat.

Because ASP.NET Core needs a server-side runtime to execute its controllers and database logic, static hosting such as GitHub Pages can't run it directly, unlike the rest of this portfolio. It's built for deployment on Azure App Service.

Conclusion & results

The Course Manager App carries a complete software development lifecycle end to end: from entity-relationship modeling for courses, students and enrollment status, through a version-controlled, cloud-ready MVC application. Entity Framework Core keeps data handling clean and consistent, while the integrated email service closes the loop with automated, real-time communication to students.
